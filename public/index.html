⚙️ Quản Lý Nguồn Phông Chữ

1. Font đã cài trong máy Windows

Tự động đọc toàn bộ font bạn đã cài vào Windows (bao gồm 390+ font 1FTV, SVN, MTD, LNTH, MJ...).

2. Thư mục chứa Font riêng của tiệm

Bạn có thể tải các bộ font chưa cài vào máy, để trong một thư mục rồi bấm "+ Thêm thư mục bất kỳ" để nạp vào phần mềm mà không cần cài nặng máy.

3. Thùng rác Font đã xoá (./trash_fonts)

Khi bạn bấm Xoá font, file gốc luôn được lưu dự phòng tại đây để khôi phục khi cần.
